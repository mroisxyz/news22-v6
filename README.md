A compact news-digest image entry for the make.fun `news-image-20261122` bounty. Running the script copies the bundled `entry.png` into the configured output directory.

## Run it

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose where the image is written (defaults to `/output`).
